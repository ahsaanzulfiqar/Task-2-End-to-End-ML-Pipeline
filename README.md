# Task 2: End-to-End ML Pipeline with Scikit-learn Pipeline API

## Objective

The objective of this project is to build a reusable and production-ready Machine Learning pipeline for customer churn prediction.

## Dataset

* Telco Customer Churn Dataset

## Methodology

* Data preprocessing using Pipeline API
* Feature scaling and categorical encoding
* Logistic Regression and Random Forest models
* Hyperparameter tuning using GridSearchCV
* Exporting trained pipeline using Joblib

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Joblib
* Matplotlib
* Seaborn

## Evaluation Metrics

* Accuracy Score
* Confusion Matrix
* Classification Report

## Key Results

* Built a reusable ML pipeline
* Automated preprocessing and training workflow
* Improved performance through hyperparameter tuning

## Skills Gained

* ML pipeline construction
* Hyperparameter tuning
* Production-ready ML workflows
* Model export and deployment preparation
